# ベンチ比較の保留画像
このフォルダは、K案へ置くベンチを選ぶ過程で生成した**静止美術比較**の履歴です。
旧ベンチの短縮画像、手描き風の再制作候補、初期の照明合成を含みます。
**素材原本は本フォルダにはなく、元の別リポジトリにそのまま保存されています。**

- `lv6-l-original-bench.png`：初期の元ベンチ配置比較（後で縦横比を修正）
- `lv6-l-refined-bench.png`：平面的な再描画候補
- `lv6-m-refined-light.png`：旧再描画ベンチ＋照明（採用候補から外す）
- `lv6-mplus-strong-light.png`：旧再描画ベンチ＋強め照明（採用候補から外す）
- `lv6-bench-repaint-study.png`：再描画案の再現可能な最終研究用画像

今回の本線は `../lv6-l-bench.png`、`../lv6-m-bench-light.png`、`../lv6-mplus-bench-light.png`。
上記の比較画像は別室への転用可能性も含め保留し、ゲームソースへの採用を意味しません。
